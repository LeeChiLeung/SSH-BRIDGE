
# SSH BRIDGE

Go言語で記述されたローカルSSHトンネルツールです。ローカルポート転送、マルチインスタンス・プロファイル、新旧2つのWebコンソール、システムトレイ常駐、およびLinux/Windows向けのビルド・配布用スクリプトをサポートしています。

## 主な利用シーン

* SSHジャンプサーバーを経由して、ローカルポートをリモートの内網（プライベート）サービスに転送する。
* 複数のトンネル設定（プロファイル）を保存し、リストやワークスペース形式で起動・停止を管理する。
* 接続ステータス、再接続ログ、ヘルスチェック、アップロード/ダウンロード速度、累積トラフィック量をローカルで確認する。
* JSON形式によるプロファイル設定のインポート/エクスポート。
* スタンドアロンバイナリ、`.deb`、`AppImage` 形式でのパッケージング。

## コア機能

* **ローカルポート転送**: ローカルのTCPポートをリッスンし、SSH先のターゲットアドレスへ転送。
* **接続維持**: 指数バックオフによる再接続、SSH keepalive、ハーフオープン接続の検出。
* **マルチインスタンス管理**: 同一プロセス内で複数のトンネルプロファイルを同時管理。
* **ローカルWebUI**: プロファイルの新規作成、編集、複製、削除、起動、停止、インポート、エクスポート。
* **システムトレイ**: コンソールの表示、アプリケーションの終了。
* **実行指標の可視化**: 通信速度、累計トラフィック、アクティブ接続数、実行ログの表示。
* **バージョン情報の注入**: `--version` フラグでバージョン、コミットハッシュ、ビルド時間を表示。

## 環境要件

* Go 1.20以上
* Linux または Windows (現在のデフォルトビルドマトリックス対象)
* `appimagetool` (AppImageパッケージング時に必要)
* `ar`, `tar`, `gzip` (`.deb` パッケージング時に必要)

## クイックスタート

### 単一のトンネルを直接実行する:

```bash
go run . \
  --ssh-host ssh.example.com \
  --ssh-port 22 \
  --ssh-user user \
  --ssh-key ~/.ssh/example_id_rsa \
  --insecure-ignore-host-key \
  --local-addr 127.0.0.1 \
  --local-port 15432 \
  --remote-host 127.0.0.1 \
  --remote-port 5432

```

これは以下のSSHコマンドと同等です：

```bash
ssh -p 22 -N -C -L 127.0.0.1:15432:127.0.0.1:5432 user@ssh.example.com

```

### バージョン確認:

```bash
go run . --version

```

### 旧版Webコンソールの起動:

```bash
go run . --web

```

### 新版Webコンソールの起動:

```bash
go run . --web-new

```

デフォルトアクセスURL: `[http://127.0.0.1:8848](http://127.0.0.1:8848)`

### トレイモードでの起動:

```bash
go run . --tray

```

トレイモードでは以下の2つが同時に起動します：

* 旧コンソール: `[http://127.0.0.1:8848](http://127.0.0.1:8848)`
* 新コンソール: `[http://127.0.0.1:8849](http://127.0.0.1:8849)`

*注：トレイメニューの「コンソールを開く」は現在、新コンソールを開くように設定されています。*

## 一般的な実行モード

### 1. ダイレクトトンネルモード

コマンドラインからの単発の転送に適しています。

### 2. `--env` によるローカルポート注入

ローカルポートを `0` に設定してシステムに自動割り当てさせる場合、`--env` を使用してシェル用のexportコマンドを出力できます：

```bash
eval "$(go run . \
  --ssh-host ssh.example.com \
  --ssh-user user \
  --ssh-key ~/.ssh/example_id_rsa \
  --local-port 0 \
  --env)"

```

出力例： `export TUNNEL_LOCAL_PORT=43017`

### 3. 新版WebUIの機能

新版コンソールでは以下の機能を提供しています：

* プロファイル一覧のダッシュボード
* 起動 / 停止 / 編集 / 複製 / 削除
* JSON形式のインポート / エクスポート
* リアルタイムステータス： `disconnected`, `connecting`, `connected`, `retrying`
* ステータス色： 未起動（グレー）、接続中（青）、成功（緑）、失敗（赤）
* ヘルスチェック： リッスン状態、SSH接続状態の監視
* ログパネル、トラフィック統計、アクティブ接続数

## 設定の保存

WebUIで設定したプロファイルは永続化されます。

**デフォルトの保存先:**

* **Linux**: `$XDG_CONFIG_HOME/timber-ssh-go/profiles.json`
* **フォールバック**: システム設定ディレクトリが利用できない場合は、カレントディレクトリの `./profiles.json`

*注：プロファイルにはSSHパスワードや秘密鍵のパスが保存されますが、秘密鍵自体の内容は保存されません。*

## ビルドと配布

デフォルトのビルドスクリプト：

```bash
./build.sh

```

特定のターゲットを指定してビルドする場合：

```bash
./build.sh build            # スタンドアロンバイナリのビルド
./build.sh deb amd64        # amd64向け .deb パッケージ
./build.sh appimage amd64   # amd64向け AppImage

```

出力先： `dist/` ディレクトリ。
Windows版はGUIサブシステムを使用してビルドされるため、起動時に `cmd` ウィンドウが表示されず、デフォルトでトレイモードに入ります。

## 既知の制限事項

* **macOSサポート**: 現在のトレイアイコンの依存関係により、Linux環境からのクロスコンパイルが困難なため、デフォルトのビルド対象に含まれていません。
* **AppImage**: パッケージングにはローカル環境の `appimagetool` とランタイムファイルが必要です。
* **仕様変更**: CLI引数やWebUIのデフォルト値は今後のアップデートで変更される可能性があります。最新情報は `--help` でご確認ください。
