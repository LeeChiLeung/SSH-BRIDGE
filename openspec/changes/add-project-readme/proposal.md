## Why

当前仓库已经具备 SSH 隧道、多实例管理、WebUI、系统托盘和多平台打包能力，但缺少统一的入口文档。新用户和后续维护者需要一个可直接使用的 README，说明这个项目是什么、怎么运行、怎么打包、配置保存在哪里，以及常见使用路径。

## What Changes

- 新增仓库级 `README.md`，概述项目定位、核心能力和支持的平台。
- 记录 CLI、WebUI、托盘模式、打包脚本和版本注入的主要用法。
- 说明 profile 存储位置、默认行为、运行依赖和当前已知限制。
- 提供面向最终用户和开发者的最小上手路径，减少口头传递成本。

## Capabilities

### New Capabilities
- `project-readme`: 为仓库提供一份完整、可执行、与当前实现一致的项目说明文档。

### Modified Capabilities

## Impact

- 新增仓库根目录 `README.md`
- 需要核对现有 CLI、WebUI、托盘、打包和版本行为，确保文档与实现一致
- 不引入新的运行时依赖或对外接口变更
