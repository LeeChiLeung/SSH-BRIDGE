## Why

当前新的 `chi + templ` 控制台已经具备基础结构，但页面文案仍然主要面向单一语言，国际化能力只停留在早期骨架阶段。现在需要把日语正式纳入支持范围，并提供用户可见的语言切换入口，让本地控制台具备可交付的多语言使用体验。

## What Changes

- 为新的 Web 控制台补齐日语页面文案，并与现有中文、英文一起纳入统一的 UI 国际化字典。
- 在控制台页面中增加明确的语言切换按钮，允许用户在中文、英文、日语之间切换。
- 定义语言解析与持久化策略，确保刷新页面或进入详情页后仍保持当前语言。
- 统一新 UI 中列表页、详情区、表单、日志与状态类文本的国际化接入方式，避免继续散落硬编码文案。

## Capabilities

### New Capabilities
- `web-ui-localization`: 为新的 `chi + templ` 控制台提供统一的多语言字典、语言解析和页面文案渲染能力，首批覆盖中文、英文、日语。

### Modified Capabilities
- `web-control-console`: 本地 Web 控制台需要新增可见的语言切换入口，并在页面导航、详情刷新和表单交互后保持当前所选语言。

## Impact

- 影响 `ui/` 下的 layout、页面组件、表单、详情面板和共用文案组织方式
- 可能引入轻量级语言上下文、字典访问器和语言持久化逻辑
- 需要同步调整新 UI 路由层与页面渲染上下文，但不改变隧道核心逻辑、profile 存储和托盘主线
